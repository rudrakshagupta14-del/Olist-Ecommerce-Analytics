# Olist E-Commerce Sales & Customer Analytics

## Project Overview

An end-to-end e-commerce data analytics project using the Brazilian E-Commerce Public Dataset by Olist.

The project focuses on sales, customers, products, sellers, payments, delivery performance, and customer reviews.

## Tools Used

- Excel
- Power Query
- PostgreSQL
- SQL
- Power BI
- DAX

## Project Workflow

Kaggle Dataset → Excel/Power Query → PostgreSQL → SQL Analysis → Power BI → Business Insights

## Key Analysis

- Sales performance
- Customer analysis
- Product category analysis
- Seller performance
- Monthly sales trends
- Delivery performance
- Customer reviews
- Repeat customers

## Dashboard

The Power BI dashboard contains three pages:

1. Overview
2. Analytics
3. Experience

## Dataset Source

Brazilian E-Commerce Public Dataset by Olist

Source: Kaggle

## Project Structure

- `1_Data` — Dataset information
- `2_Excel` — Data cleaning
- `3_SQL` — Database creation and SQL analysis
- `4_PowerBI` — Power BI dashboard file
- `5_Dashboard` — Dashboard screenshots
- `6_Documentation` — Data flow and business insights
- `7_Presentation` — Project presentation
