# Dataset

## Dataset Name

Brazilian E-Commerce Public Dataset by Olist

## Source

The dataset was obtained from Kaggle.

## Dataset Overview

The dataset contains information related to an e-commerce business, including:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Data Used in the Project

The dataset was used to analyze:

- Sales performance
- Customer behavior
- Product categories
- Seller performance
- Payment information
- Delivery performance
- Customer reviews
- Repeat customers
- Monthly sales trends

## Data Preparation

The data was initially cleaned and prepared using Excel and Power Query before being used for SQL analysis and Power BI dashboard development.

## Note

The original raw CSV files are not included in this GitHub repository because of their large file size.

The dataset was used for educational and portfolio project purposes.
